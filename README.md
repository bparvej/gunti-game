# Bangla Guti Game

A traditional Bengali board game built with Flutter. Two players take turns moving their three gutis along the board lines, aiming to line up all three in a row to win.

## Features

- Classic Bangla Guti gameplay with smooth animations
- Multiple themes and color pairs
- Customizable guti shapes: Circle, Square, Stick, and Lal Badshah
- Background themes: Teak Wood, Velvet Red, Green Mat, Moonlit Night, Marble, and Funny Dino
- Upload your own background image
- Sound effects and move counter
- Statistics tracking
- Undo moves
- How to Play guide

## Getting Started

### Prerequisites

- Flutter SDK (3.12.2 or higher)
- Dart SDK

### Installation

1. Clone the repository
2. Run `flutter pub get`
3. Run `flutter run`

## Game Rules

- 2 players, 3 gutis each
- Tap a guti to select it
- Green ring indicates legal moves (1 step)
- No jumping, no overlapping, no capturing
- Line up all 3 gutis to win!
